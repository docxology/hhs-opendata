## What this is

CSV outputs from the 100% sample-fraction run (Bernoulli sample of the ~227M-row dataset, drawn from the full data/medicaid-provider-spending.csv). Generated by `uv run run_multi_scale.py --scales 100` — which sets `MEDICAID_OUTPUT_DIR`/`MEDICAID_PLOTS_DIR` and re-runs all 40 sections of `main.py` against the sample — not by any hand-written process. Fully regenerable; coordinates (not conclusions) differ between scales, so cross-scale comparisons belong in the manuscript, not here.
