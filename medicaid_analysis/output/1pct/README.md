# `1pct/`

CSV outputs from the 1% sample-fraction run (Bernoulli sample of the ~227M-row dataset, drawn from data/sample.csv). Generated by `uv run run_multi_scale.py --scales 1` — which sets `MEDICAID_OUTPUT_DIR`/`MEDICAID_PLOTS_DIR` and re-runs all 40 sections of `main.py` against the sample — not by any hand-written process. Fully regenerable; coordinates (not conclusions) differ between scales, so cross-scale comparisons belong in the manuscript, not here.

See `../README.md` for the section-artifact map and regeneration commands.
