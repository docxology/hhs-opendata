# HHS Open Data analysis

This repository analyzes the public HHS Medicaid Provider Spending data.
The pipeline reads the raw CSV with DuckDB and publishes aggregate
tables, exploratory statistics, and figures.

- [Documentation](docs/README.md)
- [Reproduce the manuscript from archived aggregates](docs/reproduce.md) without the raw CSV
- [Read the canonical manuscript](docs/manuscript/README.md)
- [Run the full analysis](docs/medicaid_analysis.md) when the raw CSV is available
